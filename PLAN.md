# 🚀 ShopNight Tech - Development Roadmap

## 👨‍💻 Project Identity

- **Lead / Brand:** NEONDEV
- **Role:** AI-First Product Builder (Advanced Vibe Coder / NOC Manager approach)
- **Concept:** Premium Gaming Gear E-Commerce (Boutique, Visual-First Competitor to standard retail)

## 🛠️ Tech Stack

- **Core:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS v4 (PostCSS)
- **State Management:** Zustand
- **Authentication:** Clerk
- **Database:** Supabase
- **Deployment:** Vercel

## 🎨 Design System: Cyber-Glass

- **Theme:** Dark Cyberpunk (`#0a0f16` / `#05080c`)
- **Effects:** Glassmorphism (`backdrop-blur`), 3D Tilt elements
- **Neon Accents:** Cyan (`#00f0ff`), Purple (`#8a2be2`), Crimson (`#ff003c`)
- **Interactions:** Animated RGB underlines, glow borders, responsive SVGs
